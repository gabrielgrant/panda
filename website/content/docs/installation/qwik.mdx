Learn how to set up Panda CSS in a Qwik project using PostCSS.

> This guide targets Qwik v2 (`@qwik.dev/core`). Panda generates Qwik artifacts that import from `@qwik.dev/core`, so
> Qwik v1 (`@builder.io/qwik`) projects are not supported by the generated `jsx` artifacts. If you are still on Qwik
> v1, either stay on an older Panda version or avoid `jsxFramework: 'qwik'` and use the plain `css`/`recipes`
> functions, which are framework-agnostic.

### Update package.json scripts

Open your `package.json` file and update the `scripts` section as follows:

```diff {3} filename="package.json"
{
  "scripts": {
+    "prepare": "panda codegen",
    "dev": "vite --mode ssr",
    "build": "qwik build"
  }
}
```

- `"prepare"` - script that will run Panda CSS CLI codegen before each build. Read more about
  [codegen](/docs/references/cli#panda-codegen) in the CLI section.

### Configure the content

Make sure that all of the paths of your Qwik components are included in the `include` section of the `panda.config.ts`
file, and set `jsxFramework` to `qwik` to generate the `styled` factory, JSX patterns and `createStyleContext`.

```js {8, 11} filename="panda.config.ts"
import { defineConfig } from '@pandacss/dev'

export default defineConfig({
  // Whether to use css reset
  preflight: true,

  // Where to look for your css declarations
  include: ['./src/**/*.{js,jsx,ts,tsx}'],

  // Generates JSX utilities for Qwik
  jsxFramework: 'qwik',

  // The output directory for your css system
  outdir: 'styled-system'
})
```

### Configure the entry CSS with layers

Add this code to the top of the `src/global.css` file (imported in `src/root.tsx`).

```css filename="src/global.css"
@layer reset, base, tokens, recipes, utilities;
```

### Start using Panda

Now you can start using Panda CSS in your project.

```tsx filename="src/routes/index.tsx"
import { component$ } from '@qwik.dev/core'
import { css } from 'styled-system/css'
import { styled } from 'styled-system/jsx'

export default component$(() => {
  return (
    <div class={css({ p: '10', bg: 'gray.900', h: 'dvh' })}>
      <styled.button bg="blue.500" onClick$={() => console.log('clicked')}>
        Click me
      </styled.button>
    </div>
  )
})
```

</Steps>

## Troubleshooting

If you're not getting import autocomplete in your IDE, you may need to include the `styled-system` directory in your
`tsconfig.json` file:

```json filename="tsconfig.json"
{
  // ...
  "include": ["src", "styled-system"]
}
```

While Qwik v2 is in beta, production builds require a Rollup-based Vite (Vite 7). Vite 8 (Rolldown) builds currently
produce a client manifest that Qwik's SSR renderer cannot resolve event handlers from; this is a Qwik limitation, not a
Panda one.
