### Start using Panda

Now you can start using Panda CSS in your project.

```tsx filename="src/routes/layout.tsx"
import { component$, Slot } from '@builder.io/qwik'
import { routeLoader$ } from '@builder.io/qwik-city'
import { css } from 'styled-system/css'

export const useServerTimeLoader = routeLoader$(() => {
  return {
    date: new Date().toISOString()
  }
})

export default component$(() => {
  return (
    <div class={css({ p: '10', bg: 'gray.900', h: 'dvh' })}>
      <Slot />
    </div>
  )
})
```

</Steps>

## Troubleshooting

If you're not getting import autocomplete in your IDE, you may need to include the `styled-system` directory in your
`tsconfig.json` file:

```json filename="tsconfig.json"
{
  // ...
  "include": ["src", "styled-system"]
}
```

## Using Qwik v2 (beta)

Qwik v2 renamed the framework package from `@builder.io/qwik` to `@qwik.dev/core`, so the artifacts generated by
`jsxFramework: 'qwik'` (which target Qwik v1) cannot be used in a Qwik v2 app. Panda ships a separate target for it:

```js {3} filename="panda.config.ts"
export default defineConfig({
  // ...
  jsxFramework: 'qwikv2'
})
```

With `jsxFramework: 'qwikv2'`:

- All generated `jsx` artifacts import from `@qwik.dev/core` and use the `jsx()` runtime entry.
- `createStyleContext` is generated (it is not available for Qwik v1). It matches the React API (`withRootProvider`,
  `withProvider`, `withContext`, `unstyled`, `defaultProps` including JSX children) and works over SSR plus resume.
  The wrapped component must be a tag name or a `component$`.
- The file is emitted as `create-style-context.qwik.mjs` because the Qwik optimizer only processes
  `.jsx`/`.ts`/`.tsx` and `*.qwik.[mc]js` sources.

To scaffold a Qwik v2 project use the beta starter (`npm create qwik@beta`), install Panda manually with
`panda init --postcss` (the `qwik add pandacss` integration targets v1), add the `@layer` declaration to
`src/global.css`, and set `jsxFramework: 'qwikv2'` in your config.

> While Qwik v2 is in beta, production builds require a Rollup-based Vite (Vite 7). Vite 8 (Rolldown) builds
> currently produce a client manifest that Qwik's SSR renderer cannot resolve event handlers from; this is a Qwik
> limitation, not a Panda one.
